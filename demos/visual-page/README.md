# 数渊 · Data Abyss

一件交互式新媒体 / generative-art 网页：把 **china-housing**（347 座城的气候·海拔·灾害·房价）与 **china-industrial-software**（325 产品 / 43 内核 / 269 突破 / 123 政策 / 220 厂商 / 64 对标）两套真实数据，全部生灵化成漂浮在三维数渊中的发光星体。Three.js WebGL + UnrealBloom + 雾景深。手机端 full-bleed，可接入陀螺仪 / 麦克风。

## 结构

- `index.html` — full-bleed 容器 + 引入 housing 全局 script + Three.js importmap
- `app.js` — 全部场景逻辑（数据载入、通感编码、渲染、交互）
- `style.css` — full-bleed / overlay UI

数据来自**同仓库的兄弟 demo**（相对路径引用，不复制）：
- housing：`<script src="../china-housing/assets/data/{listings,enriched,hazards}.js">` → `window.HOUSING_*`
- industrial：runtime `fetch('../china-industrial-software/assets/data/...')`

## 几何体形库（`SHAPES`）— 数据驱动的多面体 + 特殊数学三维体

每颗星不再按"数据层=单一形状"，而是从其所在层的**形状调色板**里按一个子字段选一种线框立体
（线框只取 `EdgesGeometry` 的真实特征棱；CPU 合并变换 + 各自缓慢自转 + 呼吸变径）。形库 21 种（含多个 4D/5D/6D 多胞体）：

| 数据层 · 子字段 | 形状 |
|---|---|
| 城市（全部） | 发光点（保留密集星场背景） |
| 产品 · 成熟度 高/中/低 | **超立方体 8-胞体(4D)** / 方块 / **24-胞体(4D，替正八面体)** |
| 内核 · 被用度 ≥20/≥12/≥6/≥3/其余 | **6-立方体(6D)** / **penteract 5-立方体(5D)** / 星状八面体 / 正十二面体 / **16-胞体(4D)** |
| 突破 · 证据 审计/案例/其他 | **立方八面体** / **五胞体 5-cell(4D)** / **八面体棱柱(4D 胞柱，替三棱柱)** |
| 政策 · 类型 纲领/资金/部委 | 金字塔 / **超立方体(4D)** / **3-3 多胞柱 duoprism(4D，替五棱柱)** |
| 厂商 · 出身 国产/开源/国外 | 陀螺椭圆环 / **五胞体 5-cell(4D)** / **环面纽结 trefoil** |

（退役：正八面体/正二十面体/五棱柱/三棱柱→被对应 4D 形替换。重形如 6-立方体只落在寥寥几个高被用内核上，性能稳。）

**所有几何体都以「运动方向」为自转轴**（顺着各自轨迹流转，呼应"脑中概念边走边转"）：每帧取速度 `posArr−prevPos`，
对每个实体的方向做**低通滤波**（`vdir` 状态，系数随 `dt`）→ 轴平滑不抖；`_q.setFromAxisAngle(vdir, speed·t)`，
**速率随数据** `speed = shape.spin·(0.4+D.spd)`。`vl<1e-6`（瞬时静止）时保留上一方向，无 NaN → 全程平滑。
※ **棱柱（五棱柱/三棱柱，`velAxis`）额外**把长轴对齐到该方向再绕其自旋（纺锤/钻头质感，`setFromUnitVectors`）。
4D 形（超立方体/五胞体）在 4D 形变之外，也叠一层 `spin 0.05` 的轻微速度轴自转。

**多维多胞体做真·nD 运动**（`is4d` + `dim`，统一 4/5/6 维管线）：存 D 维顶点 + 棱，运行时 `projectND`
**逐帧在数个 (i, dim−1) 平面旋转、再逐维透视塌缩到 3D**（`makeND`/`hcube`/`autoEdgesND` 生成；
8-胞体 16顶/32棱、16-胞体 8/24、24-胞体 24/96、3-3 胞柱 9/18、八面体棱柱 12/30、penteract 32/80、6-立方体 64/192）。
→ 经典"内外立方体翻转/展开"、顶点穿插涌动；维度越高投影出的对称超网越密。**旋转速率随数据 `D.spd`**
（`spd4 = spin4·(0.4+D.spd)`），相位 `hash01` 去同步 → 每个超立方体处在不同的 4D 角。每实体每帧各算自己
的投影（`_localDyn` 暂存），再过位置/缩放矩阵。

特殊数学体的构造：stella octangula = 一对对偶四面体（棱集 + 其中心反演）；cuboctahedron =
12 顶点取最短等长棱 `autoEdges`；tesseract/5-cell 见上（4D）；trefoil = 参数化 (2,3) 环面纽结折线。
每形另带 ≤6 个**轨迹发射点 corners**（从棱端点去重取样）→ 彗尾从顶点而非中心拖出。

## 运动 · 三体/多体混沌 (v3)

位置不再是静态布局，而是 CPU 每帧积分的**混沌动力系统（strange attractors）**，得到非周期混沌路径。三套系统共存：

| 系统 | 实体 | 混沌参数（数据驱动） |
|---|---|---|
| Thomas attractor | 城市 / 厂商 | b = 宜居度（舒适越多越规整）；初值用经纬度播种 → 中国轮廓被混沌逐渐卷入 |
| Lorenz butterfly | 产品 / 内核 | ρ = 成熟度 |
| Rössler spiral | 突破 / 政策 | c = 年份新近度 / 目标金额 |

- 积分步长（≈角速度）由数据特征决定；麦克风 `uPulse` 加速整片宇宙的积分。
- 加载时先 warm-up 280 步把吸引子预先展开。
- 每颗星保留 `TRAIL`(桌面18/手机11) 帧历史 → 渐隐 3D 拖尾；依赖连线两端跟随积分位置、淡虚线弱化；无 bloom。
- 上层表（位置/高度/角度）现退化为吸引子的**初值/锚点**；颜色/大小/明灭仍为数据编码。

## 神经网络层（SOM + CPPN，零依赖、纯 JS/GLSL）

把 neural network 同时当作**技术**与**话题**引入：作品不只画数据，而是**当着观众的面，
让数据自己学出一副骨架**。两张真神经网络在浏览器里就地运行，无任何 ML 库。

### A. SOM 自组织神经网格（Kohonen 竞争学习）

每颗星先被压成一枚 **26 维特征向量**（`makeFeat`）——城市填 0..9（宜居度/温差/日照/PM2.5/
海拔/灾害/单价/租售比/外流/年均温），工业填 10..19（出身 one-hot/成熟度/本地化/置信度/
年份/内核被用度/目标金额/证据等级/替代数），20..25 是 entity-type one-hot（×1.5 让分层占优）。
`finalize()` 按列 min/max 归一化为 `featM (N×26)`。

`buildSOM()` 在 boot 的 loader 遮挡下**一次性整训**一个 `9×7×5 = 315` 神经元的 3D Kohonen
晶格（桌面 26 epoch / 手机 14）：竞争找 BMU、邻域协同更新，α 与邻域半径 σ 指数衰减。
收敛后每颗星映射到其 BMU 的晶格坐标 → 写进**原本恒为 `CENTER` 的锚点 `anc`**；
晶格本身画成一张发光神经网（neighbor 连线，`aGlow` = 落入该神经元的星数 / `latticeMat`）。
**晶格→世界用球壳映射**（`nodeWorld`）：ix=经度（环视一圈）· iy=等面积纬度（避开极点）·
iz=球壳厚度（`SOM_R` 内/外半径 55→120），并对每个节点做确定性抖动 → 一张**包住视角的不规律
有机球面**，而非平面方盒；观者立于球心，呼气时被这层神经球壳环抱。

### 呼吸式自组织（让"学习"看得见）

全局呼吸量 `gOrg`（`animate()` 里由 `cos` + smootherstep 生成，长周期 ~48s，麦克风 `uPulse`
提速）在 `writeWorld()` 里插值：
- 有效锚点 `effAnc = CENTER + (anc − CENTER) · gOrg`
- 有效缩放 `effScl = scl · (1 − (1−0.5)·gOrg)`

→ **吸气**（gOrg→0）所有吸引子回到共心、重叠成混沌团，神经晶格隐去；
**呼气**（gOrg→1）星群铺开成学出来的神经地图、混沌缩成锚点周围的小笔触、晶格显形。
开场即从重叠态缓缓呼气，第一幕就是"深渊学会自己的形状"。

### B. CPPN 神经背景场（天穹 shader 里的微型 MLP）

`bgMat` 背景不再只是 fbm，而是一个 **`5→8→8→2` 的 CPPN**（compositional pattern-producing
network）逐像素前向：输入 `[dir.xyz, sin t, cos t]`，tanh 层 + sin 层，输出 2 个标量场去
**驱动既有 off-color 调色板的色相参数与 domain-warp**（不直接出 RGB → 防随机网络翻车、锁住美学）。
138 个权重由数据聚合量（climWarm、产品/突破/政策计数）经 mulberry32 PRNG **确定性播种**
（`seedCPPN`）一次性上传——"这场梦由数据塑形"。最后对**红主导像素**（`col.r − max(col.g,col.b)`）
做压暗 → 红改为**黑红**，其余色相不变。

## 交互

- 输入统一走 **Pointer Events**：**单指/鼠标拖动** = 环视（改 yaw/pitch）；**双指捏合** = 调焦距（FOV，捏开放大）；
  桌面**滚轮**亦调焦。canvas 设 `touch-action:none` 防浏览器手势劫持。
- **点击/轻触一颗星 = 锁定追踪**：相机以它为中心**环绕**（`applyLook` 在 `focusBlend` 上插值，相机=目标+视向·`ORBIT_R`，
  `lookAt` 目标；`_starSmooth` 平滑跟踪它在混沌中的漂移）；拖动/陀螺变成**绕它旋转**。点空白处 → 缓缓退回正中心。
- 弹卡刻意**艺术化、不易读**：不显类型（城市/产品/…），只留**名称 + 一行裸关键词**（`formatKeywords`，去标签、小写、宽字距、低透明）。
- **陀螺仪以「增量」驱动**（`deviceorientation` 的 α/β 帧间差 → 累加到 yaw/pitch）：与手指拖动**叠加共存、互不覆盖**，
  且避开绝对罗盘坐标在手机倾斜时的方向混乱。「开启手机感应与声音」后生效。
  两段**阻尼**过滤传感器微抖：①**软死区** `gyroGate(d)=d·a²/(a²+t²)`（t=0.15°）→ 0.05° 抖动仅过 10%、0.4° 真实运动过 88%、≥2° 几乎无损，无硬截断不卡顿；②**泄漏积分** damper（每帧只应用 `dt·14` 比例、余下顺延，保积分）→ 应用过程平滑。
- 麦克风环境声 → `uPulse` 驱动整体明灭/呼吸提速。
- 传感器（陀螺仪/麦克风）需 **https + 用户授权**，仅在真机部署页生效

## 运行

静态页，需经 http(s) 提供（ES module + fetch 不能跑 file://）：

```bash
# 仓库根目录
python3 -m http.server 8099
# 打开 http://localhost:8099/demos/visual-page/
```

GitHub Pages 上直接访问 `/demos/visual-page/` 即可，sensors 自动可用。
