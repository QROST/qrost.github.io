哪里既宜居，又便宜？

121 套来自全国小城市、县城与度假区的二手房挂牌样本，覆盖 18 个省 / 直辖市。 便宜只是起点——这里把每套房的气候舒适度、冬夏气温、年降水、海拔、 到医院 / 火车站 / 机场 / 海岸的距离，以及省级自然灾害风险， 和价格放进同一张表横向对比，帮你挑出住着舒服、风险可接受、又花得起的地方。

数据更新于 2026-01 ~ 2026-04。每行是单一挂牌报价（往往是当地能找到的最便宜的房子），属轶事样本， 非市场指数；宜居与灾害多为区域/省级粗略口径，不构成投资或安家建议。口径见说明。

便宜 × 宜居 · Cheap ↔ Livable

每个点是一套房：横轴总价（越左越便宜）、纵轴舒适月数（月均温 15–26℃ 的月份，越上越多），颜色越蓝 = 年温差越大（四季越分明）、越青 = 全年越平稳。左上角那批既便宜、舒适月又多的房子，正是这份清单想帮你找到的。

说明 · Methodology

宜居指标如何得来

  • 气温 / 降水：Open-Meteo ERA5 2014–2023 月度均值；年降水为 12 个月均值之和。
  • 舒适 / 极端按「天」判定：取 ERA5 2014–2023 的日气候（年内逐日做 10 年平均，再 15 天平滑去噪），舒适 = 日均温 15–26℃，极端 = 日均温 < 0℃（严寒）或日均高温 ≥ 33℃（酷热）。表格 / 弹窗 / 散点显示具体日期范围（如「11月1日–次年3月20日」，跨年自动环绕）；弹窗温度曲线为 365 天日曲线（绿=舒适段、红=极端段）。各省对比为按日的连续条（红段 = 该省有小区当天极端，色深 = 占样本比例，竖线为月界）。日级呈现精确，但源自 10 年再分析平滑，边界不确定度约 ±1 周，非逐日预报。
  • 年温差（℃）= 最热月均温 − 最冷月均温，直接反映季节波动幅度；越小越平稳，越大越四季分明。不再使用含糊的"宜居指数"（口径与单位不透明、易误导，已移除）。
  • 气候类型仅由两个透明数字（年均温 Ta、年温差 R）按公开阈值判定，可复算：四季分明 R≥20；长夏无冬（一直暖）最冷月≥18℃；常年凉冷（一直凉）最热月≤18℃；夏热冬暖 最热月≥27℃且最冷月≥8℃；四季如春 R≤12 且 14≤Ta≤22；常年温暖 R≤14 且最冷月≥12℃；冬暖夏凉 最热月≤26℃；其余为温和过渡。
  • 海拔：Open-Meteo Copernicus DEM；医院/火车/机场/海岸距离：最近一处的直线距离（OSM Overpass + 离线机场/海岸线）。
  • 供暖：按秦岭–淮河集中供暖线的省级口径——以北为集中供暖，江苏/安徽跨线为部分供暖，以南分无·冬暖（暖和、无需供暖）与无·湿冷（冬季湿冷却无集中供暖的"夹心层"）。严寒本身不算灾害，已由气候指标体现，供暖列只回答"冬天有没有暖气"。
  • 连续底图（等温线/降水/海拔）：在中国陆地上按 1° 网格采样 ERA5（2019–2023）与模型海拔，等值线由 marching-squares 抽取——粗略定向用，非精细气候图。
  • 单价 = 总价 ÷ 面积；毛回报 = 月租×12 ÷ 总价、回本年限 = 总价 ÷ 年租金（毛口径，作参考保留）。
  • 房龄 / 完工年份：逐个小区联网调研贝壳 / 安居客 / 房天下的「建成年代 / 竣工年限」字段——查到才记、附来源、核对城市防重名、绝不臆测（搜索摘要里的年份若打开页面核不到即弃用）；已覆盖 47 / 121 套，其余公开渠道暂无、显示「年代未知」。色条 绿=新 → 琥珀=老，悬停看建成年份与来源；多期楼盘取最早一期。

务必注意的局限

  • 每行是单一挂牌报价，多为当地最低价房源，不代表区域均价；价格含"约"，部分为公寓/度假盘，产权与流动性差异大。
  • 气候 / 海拔取自小区的定位坐标，而小区名常回退到街道 / 城市级，故为区域近似；周边设施在小城可能缺漏。
  • 地震带 / 台风暴露 / 主要灾害为省级、定性口径（公开地理气候资料 + 应急管理部历年灾情的概括）。每种灾害都标复发频率——几乎年年 / 数年一遇 / 约十年一遇 / 数十年一遇 / 百年级罕见，因为"年年一次的台风"和"数十年一遇的大地震"完全不同；频率非严重度，严重度见悬浮说明。低温/严寒不计为灾害（属气候，已由宜居指标体现），仅保留会致灾的离散事件如暴雪、凝冻。此口径非点位灾害模型、非工程依据，仅供并排比较"这一带通常会出什么状况、多久一次"。
  • 部分缺口由子代理联网调研补充（页内标「调研」，坐标仍由我们自行换算校验）。
  • 仅供研究与好奇心，非投资、安家、法律或税务建议。
