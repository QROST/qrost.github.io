哪里既宜居，又便宜？

249 套来自全国小城市、县城与度假区的二手房挂牌样本，覆盖 26 个省 / 直辖市。 便宜只是起点——这里把每套房的气候舒适度、冬夏气温、年降水、海拔、 到医院 / 火车站 / 机场 / 海岸的距离，以及在地自然灾害风险， 和价格放进同一张表横向对比，帮你挑出住着舒服、风险可接受、又花得起的地方。

数据更新于 2021-03 ~ 2026-07。每行是单一挂牌报价（往往是当地能找到的最便宜的房子），属轶事样本， 非市场指数；宜居与灾害为粗略近似口径（灾害已细化到小区，仍含估算），不构成投资或安家建议。口径见说明。

数据来源与整合

挂牌与旅居信息种子来自小红书博主「FIRE规划师」与「包子全是水」无偿分享的房产 / 旅居笔记——前者主要对应其 2026-04 系列帖子，后者主要对应其 2025-06 系列帖子。经整合后，QROST 联网补充了若干样本，并独立计算气候 / 海拔 / 基础设施距离 / 灾害频率等宜居维度（Open-Meteo、OpenStreetMap 及公开史料）。

宜居指标如何得来

  • 气温 / 降水：Open-Meteo ERA5 2014–2023 月度均值；年降水为 12 个月均值之和。
  • 舒适 / 极端按「天」判定：取 ERA5 2014–2023 的日气候（年内逐日做 10 年平均，再 15 天平滑去噪），舒适 = 日最低 ≥8℃ 且日最高 ≤26℃，极端 = 日均温 < -5℃（严寒；0～-4℃ 干冷不计）或日最高温 ≥ 33℃（酷热，更贴近体感不适而非气象 35℃ 预警线）。舒适与极端互斥（同日若满足两者，计为极端）。为宜居口径，非官方灾害预警。表格 / 弹窗 / 散点显示具体日期范围（如「11月1日–次年3月20日」，跨年自动环绕）；弹窗温度曲线为 365 天日曲线（绿=舒适段、红=极端段）。各省对比为按日的连续条（绿段 = 该省有小区当天舒适、红段 = 该省有小区当天极端，色深 = 占样本比例，竖线为月界）。日级呈现精确，但源自 10 年再分析平滑，边界不确定度约 ±1 周，非逐日预报。
  • 历史气温极值（最高 / 最低）：优先取区镇 / 区县维基百科气候数据模板中的国家站全历史记录；无模板时取 Open-Meteo ERA5 1940–2023 日极值（≈25 km 格点，非站址记录）。表格悬停可见来源与粒度。
  • 扩展日气候（与气温同一次 ERA5 逐日拉取，10 年平滑后年度汇总，已烘焙入库）：高湿日 日均 RH≥70%；降雪日 日降雪>0.05 cm；大风日 日最大风速≥10 m/s；年日照 为逐日日照时数之和（小时）；体感舒适日 日平均体感温 10–28℃。
  • 年温差（℃）= 最热月均温 − 最冷月均温，直接反映季节波动幅度；越小越平稳，越大越四季分明。不再使用含糊的"宜居指数"（口径与单位不透明、易误导，已移除）。
  • 气候类型仅由两个透明数字（年均温 Ta、年温差 R）按公开阈值判定，可复算：四季分明 R≥20；长夏无冬（一直暖）最冷月≥18℃；常年凉冷（一直凉）最热月≤18℃；夏热冬暖 最热月≥27℃且最冷月≥8℃；四季如春 R≤12 且 14≤Ta≤22；常年温暖 R≤14 且最冷月≥12℃；冬暖夏凉 最热月≤26℃；其余为温和过渡。
  • 海拔：Open-Meteo Copernicus DEM；医院/火车/机场/海岸距离：最近一处的直线距离（OSM Overpass + 离线机场/海岸线）。
  • 供暖：按秦岭–淮河集中供暖线的省级口径——以北为集中供暖，江苏/安徽跨线为部分供暖，以南分无·冬暖（暖和、无需供暖）与无·湿冷（冬季湿冷却无集中供暖的"夹心层"）。严寒本身不算灾害，已由气候指标体现，供暖列只回答"冬天有没有暖气"。
  • 连续底图（等温线/降水/海拔）：在中国陆地上按 ERA5 2014–2023 采样——全国视图 1° 网格（含等值线），放大到省内懒加载 0.25°（≈25 km） 格点填色，与小区圆点气候互补；粗略定向用，非精细气候图。
  • 单价 = 总价 ÷ 面积；毛回报 = 月租×12 ÷ 总价、回本年限 = 总价 ÷ 年租金（毛口径，作参考保留）。
  • 美国样本（加州）：挂牌价来自 Compass / Realtor 等公开页面；纯租赁公寓（如 90293）无二手房成交价时，总价按 月租×12 ÷ 4.5% 资本化率 折算隐含资产价值（便于与可售样本比回报），并在调研 JSON 注明来源；机场/海岸距离用 SoCal 离线顶点而非中国数据集。
  • 房龄 / 完工年份：逐个小区联网调研建成年代——先查贝壳 / 安居客 / 房天下的「建成年代 / 竣工年限」字段，查不到的（老破小 / 厂矿家属院 / 村镇）再旁敲侧击：老旧小区改造名单、厂史 / 三线建设史料、政府征收公告、社媒讨论（贴吧 / 知乎 / 小红书）、小区名最早上网时间（建成上界）。附来源、核对城市防重名、绝不臆测（搜索摘要的年份若打不开页面核实即弃用；纯类别空想一律不记）。能核实到精确年份的入库展示；仅得可信来源的年代级估算时标「约」以示非精确；公开渠道无痕的显示「年代未知」。色条 绿=新 → 琥珀=老；浅灰=未交付期房（负房龄，预计交付年晚于当前年），悬停看建成/交付年份与来源；多期楼盘取最早一期。

舒适日 / 极端日判定

  • 数据：Open-Meteo ERA5 2014–2023 逐日气温 → 年内同日期做 10 年平均 → 15 天圆周平滑（固定 365 天历法）。
  • 舒适日：平滑后 日最低温 ≥8℃ 且日最高温 ≤26℃（全天温区落在舒适带内），且当天不算极端。
  • 极端日：平滑后 日均温 < -5℃（严寒；0～-4℃ 干冷不计）或 日最高温 ≥ 33℃（酷热；比气象 35℃ 预警线更贴近日常体感不适）。
  • 互斥：舒适与极端不重叠——已标为极端的日子不再计舒适（表格绿/红条、排行天数均如此）。
  • 性质：宜居对比口径，非中国气象局灾害预警；日期边界因平滑约有 ±1 周 不确定度。

不利环境·敏感地点

  • 数据来源：OpenStreetMap / Overpass（免费、无密钥、WGS-84）；按 haversine 对全国参考点集取最近距离。
  • 大型变电站 = ≥220kV。
  • 「敏感地点」：仅 OSM 公开的军事用地；覆盖稀疏，无标记 ≠ 不存在；用于居住规避参考，非官方或定位用途。
  • 口径：粗略宜居「越远越好」信号，非精密工程或灾害预警。

购房政策（国家 + 各市）

  • 粒度：政策按地级市归并（限购 / 限贷 / 落户 / 补贴 / 公积金 / 二手房指导价 / 棚改 / 资源枯竭 / 七普人口），国家级常量（LPR / 首付下限 / 契税分档 / 认房不认贷 / 户籍改革 / 保交楼）单列。一套房按其市映射到对应政策。
  • 溯源：每个政策字段附来源链接 · 时点 · 置信度（高=政府原文 / 中=权威媒体或地方门户 / 低=间接推断）；查无可靠源即标「未知」，绝不臆测。多轮联网调研 + 对抗式事实核查（仅下调、不上调置信度）。
  • 决策漏斗：能买（限购）→ 划算（契税 + 月供）→ 落户（门槛）→ 宜居（本页评分）→ 交付（二手现房无烂尾风险）。五闸为提示性，非审批结论。
  • 时效：政策是快照，利率 / 限购 / 补贴变动频繁；购房前务必向当地住建局 / 不动产登记中心 / 公积金中心核实最新口径。总价 / 月供为粗略估算，不含贷款审批、评估价差异、维修基金等。

务必注意的局限

  • 每行是单一挂牌报价，多为当地最低价房源，不代表区域均价；价格含"约"，部分为公寓/度假盘，产权与流动性差异大。
  • 气候 / 海拔取自小区的定位坐标，而小区名常回退到街道 / 城市级，故为区域近似；周边设施在小城可能缺漏。
  • 主要灾害·频率已细化到每个小区：先联网调研各地级市的真实灾情史（应急部风险普查 / 气象灾害年鉴 / 地方志 / 新闻，带来源）定「有哪些灾害」，再按小区坐标物理细化频率/适用——台风（含风暴潮海岸增水，按离海岸距离；深内陆自动剔除）、滑坡/泥石流（灾情口径「地质灾害」，含山体滑坡、泥石流、崩塌；不含地震）按地形起伏（平原剔除，但采煤沉陷型保留），气候型（暴雨 / 洪涝 / 干旱 / 暴雪 / 凝冻）保留区域级；暴雨与洪涝在表内合并为暴雨洪涝（频率取较高档）。每灾标复发频率——几乎年年 / 数年 / 约十年 / 数十年 / 百年级罕见（"年年的台风"≠"数十年的大地震"）；频率非严重度。地图着色取突发地球物理灾（地震 / 台风 / 风暴潮 / 滑坡/泥石流等，随地点真实变化的那几类）的最频档，地图用中性灰阶表示常见度（更常见→更深灰），非严重度警示色；表格 / 弹窗仍列全部灾害。低温严寒不计（属气候）。频率含估算成分，粗略近似、非点位工程模型，仅供并排比较"这一带通常出什么、多久一次"。
  • 部分缺口由子代理联网调研补充（页内标「调研」，坐标仍由我们自行换算校验）。
  • 仅供研究与好奇心，非投资、安家、法律或税务建议。
