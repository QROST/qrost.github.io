生成音乐引擎 · 参考

Data Abyss（lo-fi）与 Neon Abyss（trance）两套 zero-dependency Web Audio 引擎："数据 → 自组织地图 → musicDNA → 曲子"，加上一层实时交互驱动。本页速查每一条映射：谁影响音乐、怎么影响、如何交互引导。

核心律 同一片宇宙 → 同一首曲 引擎内 零 Math.random 变化源 涌现签名 sig → 确定性 PRNG

◇musicDNA 的数据溯源

每个 DNA 字段最终都追得到具体数据/SOM 量。（visual-page/app.js:1073–1091 ≡ neon-abyss/app-club.js:1102–1120）

字段来自怎么算
warm房源年均温全国均温 → climWarm=clamp((均温−5)/18, .12, .9)
hueStar最密簇色相密度 argmax 得 dStar；该簇成员 audioTone（渲染 HSL 色相）的圆均值
concentration密度峰/均比clamp((density[dStar]/meanD)/6, 0,1)
populatedFrac簇数量有星神经元数 populated / M（晶格占用率）
speedMean簇速均值各簇平均星速 spd[] 的均值 / 0.6（spd 本身数据驱动，如城市=钱×气候躁动×老龄）
speedSpread簇速离散度各簇平均速的标准差 / 0.4
domType最密簇主导类型densest 神经元权重的 type one-hot（列 20..27）argmax
motif最密簇原型前 8 维⌊clamp(W[dStar][k],0,.999)·5⌋, k∈[0,8) → 8 个 [0,4] 整数
sig整张涌现态FNV-1a 混入 climWarm/concentration/populatedFrac/csMean/speedSpread/hueStar/motif[8] + 每个神经元的归一化密度
决定性来源：SOM 训练（权重初始化 + 洗牌）是整条管线里唯一用 Math.random 的地方——它就是每次开页"不同宇宙"的来源。往下 DNA→sig→PRNG→曲全部确定：固定 SOM 就会复现一模一样的曲。类型槽：0=房 1=工业产品 2=kernel 3=药企 4=政策 5=vendor 6=药品 7=收容所猫。

②你实时定"此刻怎么走"

每帧 update({dt,pulse,gOrg,yaw,pitch,fov,focus,view})。Data Abyss(lofi) 高度可玩，读全部实时输入；Neon Abyss(trance) 只读 focus + view.clHue。

实时输入控制效果用于
focus（点击实体）lofi：按 TRACK[group] 定 targetKey+进行+能量，弹电钢；trance：一个 lead 音"你追踪什么，就唱什么"；调 ≤2 半音/乐句平滑靠拢both
view.clHue（注视的簇色相）旋律落音颜色（色环最短弧 ~250ms 平滑）看哪片自组织，旋律就染那个色，不跳音both
view.clEnergymelGate 密度 + 八度跳 + 应答概率看能量高的簇→旋律更密更跳lofi
view.dom旋律 FM 音色 MEL_TONE[dom]主导数据层换旋律音色lofi
pitch（俯仰）master lowpass 7600+pitchN·2400Hz抬头变亮，低头变暗lofi
yaw（转向）旋律 stereo pan sin(yaw)·0.4旋律左右声道摆动lofi
fov（缩放）reverb send 0.07+fovN·0.1广角更湿更空间，长焦更干更近lofi
gOrg（呼气量）ghost hats / comp / 旋律密度门（ex>0.35~0.45）呼气加花铺开，吸气收lofi
pulselofi=mic RMS（输入）：顶亮度/氛围/加速宇宙；trance=beatPulse（输出给视觉）方向相反：声音驱动画面 vs 节拍驱动画面both

lofi Data Abyss

4 小节乐句 结构
动机每 2 小节微变异（±1）
调每乐句 ≤2 半音向 targetKey 靠拢
每乐句重掷加花开关 → 无两句全同
intro（首小节只和弦+底噪）
drop-breakdown（每 16 小节前 2 撤鼓）
8 小节末尾 snare fill · hat 三连滚
kick 侧链 duck 和弦 → lo-fi "pump"

trance Neon Abyss

40 小节段落编排
intro 0–7 · build 8–15 · drop 16–31 · breakdown 32–39
four-on-the-floor（kick 落 0/4/8/12）
build：riser env=frac² 渐强扫频
drop 入口：一记 impact（60→30Hz thud）
supersaw 小调 stab（滤波包络 4k→1.2k）
sidechain：非鼓声部每 kick −8dB/150ms 泵
beatPulse 每 kick=1 → 甩给视觉

◇两页关键区别

lofi Data Abysstrance Neon Abyss
musicDNA 计算完全相同（逐字节）
消费的 DNA全部字段子集（不用 populatedFrac / domType / groove）
实时交互相机/注视/呼吸/焦点/mic 全读 → 强可玩只读 focus + view.clHue；相机/呼吸/pulse 不读
pulse 方向mic 输入：声音驱动宇宙beatPulse 输出：节拍驱动视觉（无 mic）
动态来源你的交互40 小节段落自走
底色暖·干·慵懒（高频 −4dB，有黑胶噪）亮·响·数字（高频 +3dB，重限制器）

一句话：Data Abyss 是"你用视角和动作演奏它"；Neon Abyss 是"曲子自己走段落、把节拍甩给画面"。

◇交互速查 · 如何引导音乐

你做听到（主要指 lofi）
点击某个星（尤其某数据类型）旋律与调性/和声整体朝那个数据主题偏，并弹一个电钢音；下个乐句边界平滑到位
点空白处取消缓缓回到基准调（"吟唱"解决回家）
看向某片彩色簇旋律落音颜色跟着那簇色相走（平滑不跳）
看能量高的簇旋律更密、更爱跳八度、更多应答
抬头 / 低头整体变亮 / 变暗（master lowpass）
左右转旋律在左右声道摆动
拉广 / 长焦缩放更湿更空间 / 更干更近（reverb）
让它呼吸（呼气）编排加花铺开，吸气收
进 mic 律动模式 + 出声音乐静音，环境声当脉冲加速整个宇宙
刷新页面新 SOM → 全新一首曲（两页都是）

◇诚实注记

trance 的几处已知实况：
· domType 与 populatedFrac 在 trance 里只进 sig，代码没直接分支消费。
· _onBar 每小节把 curProgIdx 重置回 baseProgIdx → trance 运行时不换和弦进行（每首固定，只在固定进行内每 2 小节推进和弦 + 每 4 小节动机微变异）。
· trance 不读 pitch/fov/yaw/pulse/gOrg——它的动态全来自段落（bar 计数），FOV/pulse 是单向（引擎 beatPulse → 视觉）。
· beatPulse 衰减 *0.86/帧是帧率相关（非 dt 归一），高帧率下墙钟衰减更快。
· 旋律 pan 用 createStereoPanner，不支持的 ctx 上静默 no-op。
